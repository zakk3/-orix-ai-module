## Технологический стек

Проект разработан на языке Python 3.11.

### Backend / расчёты

- `statistics` — стандартная библиотека Python для базовых статистических расчётов.
- `pydantic` — валидация входных и выходных моделей данных.

### LLM

- YandexGPT используется через REST API.
- `requests` применяется для отправки HTTP-запросов к LLM API.

### UI

- `streamlit` используется для создания веб-интерфейса.
- CSS используется для кастомизации внешнего вида интерфейса.

### Хранение данных и конфигурация

- JSON используется для хранения golden set эталонов.
- `.env` используется для хранения переменных окружения и API-ключей.
- `python-dotenv` используется для загрузки переменных окружения из `.env`.
