# Metrics

## Metric 1 — Чистые потери к бизнес-индикатору

Сравнивает уровень чистых потерь Моего банка относительно бизнес-индикатора со средним значением по кластеру.

## Metric 2 — Уровень возмещения прямых потерь

Сравнивает уровень возмещения прямых потерь Моего банка со средним значением по кластеру.

## Metric 3 — Распределение по бакетам потерь

Анализирует распределение прямых потерь по бакетам и сравнивает структуру банка со структурой рынка.

## Metric 4 — Динамика чистых потерь за период

Анализирует динамику чистых потерь банка за несколько кварталов и сравнивает её с рынком.

## Metric 5 — Распределение прямых потерь по источникам риска

Сравнивает структуру источников риска Моего банка со структурой банков-аналогов.
