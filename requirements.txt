# Отчет: Выбор технологического стека ИИ-модуля «Орикс»

**Направление:** Банковская аналитика (управление рисками и КПУР).  
**Цель:** Создание MVP для автоматической генерации выводов с точностью более 95% и соблюдением требований безопасности данных.

---

## 1. Выбор ИИ-моделей (LLM)
Для работы в банковском секторе выбрана стратегия использования отечественных моделей, развернутых в закрытом контуре или через защищенные API внутри РФ.

* **Основная модель (Генератор):** `YandexGPT 3` или `GigaChat Pro`.
    * *Обоснование:* Поддержка специфики российского финсектора и отсутствие рисков передачи данных за рубеж. 
* **Метод настройки:** **Few-shot Prompting** (In-Context Learning).
    * *Суть:* Мы не проводим дорогостоящее переобучение модели. Вместо этого в каждый запрос к ИИ включается «инструкция» и 3–5 эталонных примеров из нашего **Golden Set**. Это позволяет модели мгновенно адаптироваться под стиль аналитиков «Орикса».
* **Валидатор:** `YandexGPT Lite`. 
    * *Суть:* Вторая, более быстрая модель, которая проверяет итоговый текст на соответствие исходным цифрам.

---

## 2. Технологический стек разработки

### Backend и работа с данными
* **Язык:** `Python 3.10+`.
* **Математический модуль:** `Pandas`, `NumPy`. 
    * *Функция:* Все расчеты (доли потерь, динамика, нарушения лимитов КПУР) выполняются программным кодом. ИИ получает на вход уже вычисленные факты, что исключает математические ошибки.
* **LLM-фреймворк:** `LangChain`. 
    * *Функция:* Управление цепочками промптов и интеграция с моделями.
* **Векторная база данных:** `FAISS` или `ChromaDB`. 
    * *Функция:* Хранение «Золотого набора» (Golden Set) в виде векторов для быстрого поиска наиболее подходящих примеров под конкретный тип данных.

### Интерфейс и DevOps
* **UI-фреймворк:** `Streamlit`. 
    * *Функция:* Быстрое создание веб-интерфейса для загрузки JSON/XML и демонстрации отчетов.
* **Экспорт:** `ReportLab` / `FPDF`. 
    * *Функция:* Генерация финальных аналитических заключений в формате PDF.
* **Среда разработки:** Экосистема **Сфера** (`Сфера.Код`, `Сфера.Задачи`).

## 3. Ключевые термины (Глоссарий)

| Термин | Описание |
| :--- | :--- |
| **Golden Set** | Набор образцовых пар «данные — вывод», на которые ИИ ориентируется как на идеал. |
| **Галлюцинации** | Риск выдумывания фактов нейросетью. Нивелируется за счет предварительных расчетов на Python. |
| **КПУР** | Ключевые показатели уровня риска. Критически важные метрики для банковского мониторинга. |
| **Детерминизм** | Подход, при котором математика считается жестким кодом, а не «творческим» ИИ. |

---

## 4. Резюме архитектуры
Решение строится по принципу **«сначала расчеты, потом описание»**. Это гарантирует, что из 6 типов требуемых выводов (от анализа потерь до бенчмарков) каждый будет содержать 100% достоверные цифры, облаченные в качественный естественный язык.
