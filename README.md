# Orix AI Analytics Module

## Описание проекта

Orix AI Analytics Module  это AI-модуль для анализа операционных рисков банка на основе данных ОРИКС.

Проект сравнивает показатели Моего банка со средними значениями по рынку, кластеру или банкам-аналогам и формирует аналитический вывод на русском языке.

Главная идея проекта  разделить расчёты и генерацию текста.
Все числовые расчёты выполняются на стороне Python, а LLM используется только для формулировки итогового аналитического вывода.

Такой подход помогает снизить риск ошибок в расчётах и уменьшить вероятность некорректных выводов со стороны модели.

## Как работает проект

Общий процесс работы системы:

1. Пользователь выбирает нужную метрику.
2. Система получает входные данные.
3. Данные проходят проверку.
4. Python выполняет расчёты и определяет сценарий.
5. LLM формирует аналитический текст на основе готовых расчётов.
6. Итоговый результат проверяется и выводится пользователю.

## Метрики проекта

| № | Метрика                                                                            | Код                     |
| -- | ----------------------------------------------------------------------------------------- | -------------------------- |
| 1  | Чистые потери к бизнес-индикатору                            | `loss_share`             |
| 2  | Динамика прямых потерь                                                | `direct_losses_dynamics` |
| 3  | Распределение по бакетам потерь                               | `loss_buckets`           |
| 4  | Уровень возмещения прямых потерь                             | `recovery_level`         |
| 5  | Распределение прямых потерь по источникам риска | `concentration`          |


## Роль LLM

LLM не выполняет математические расчёты самостоятельно.

Модель получает уже готовые значения, сценарии и аналитические признаки, после чего оформляет результат в связный деловой текст.

Это позволяет сохранить точность расчётов и использовать LLM только для улучшения качества итогового вывода.

## Особенности проекта

* расчёты отделены от генерации текста;
* сценарии определяются на стороне Python;
* LLM используется только для оформления аналитического вывода;
* данные проходят проверку перед обработкой;
* результат формируется в понятном аналитическом стиле.
